# 화면 구성

## 1. 상단 바 (항상 떠 있는 한 줄)

화면 귀퉁이(기본: 오른쪽 위)에 붙는 얇은 막대. 항상 위에 표시되고, 작업표시줄·Alt+Tab에는 나타나지 않으며,
클릭해도 다른 창의 포커스를 빼앗지 않습니다.

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ ● 실행 2  ◌ 대기 1  ✕ 실패 1 │ ▶ 실행 중 3DMaker sample2 77% ≈14:32 │ ⏸ 대기 SBS 변환 │ ≡ │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- 왼쪽: 상태별 개수 요약 (색 + 기호 + 글자).
- 가운데: 진행 중·주의가 필요한 작업 칩. `기호 상태이름 작업이름 현재단계 진행률 ≈예상완료`.
  갱신이 끊긴 작업은 `⚠ 갱신 없음 5분`처럼 표시. 최근 완료/실패 작업은 일정 시간 칩으로 남음.
- 칩 클릭 → 상세 창이 열리고 해당 작업이 선택됨. `≡` → 상세 창.
- 우클릭 메뉴: 위치(왼쪽 위/오른쪽 위/왼쪽 아래/오른쪽 아래), 항상 위, 완료 작업 칩 표시, Windows 시작 시 실행, 종료.
- 왼쪽 끝을 잡고 끌면 위치를 옮길 수 있고, 놓으면 가장 가까운 귀퉁이로 붙습니다.

## 2. 상세 창 (작업 목록 + 선택한 작업 상세)

```
┌ 작업 목록 ───────────────────────────────────────────────────────────────┐
│ 상태          │ 작업 이름              │ 현재 단계        │ 진행률   │ 예상 완료   │
│ ▶ 실행 중     │ 3DMaker 영상 생성·측정 │ sample2 생성     │ 77% (단계)│ ≈14:32     │
│ ⏸ 입력 대기   │ SBS 변환               │ -                │ -        │ -          │
│ ✔ 완료        │ MpdMaker 분석          │ 보고서 저장      │ 100%     │ 13:02 완료  │
│ ✕ 실패        │ 인코딩 테스트          │ 인코딩           │ 31%      │ -          │
├ 상세 ───────────────────────────────────────────────────────────────────┤
│ 3DMaker 영상 생성·측정   [실행 중]   입력: sample2   프로젝트: 3DMaker        │
│ 시작 11:20:05 · 경과 1:11:35 · 마지막 갱신 12:31:40 (3초 전)                  │
│ 현재 단계 ETA ≈ 14:32 (예상, 남은 2:57)   전체 ETA: 정보 부족                 │
│                                                                           │
│ 단계                     상태      처리량            속도         진행률       │
│ 1 sample2 영상 생성·측정  실행 중   462 / 599 frames  0.78 frames/s  77%      │
│ 2 sample3 영상 생성·측정  대기      -                                       │
│ 3 결과 파일 검증          대기                                              │
│ ...                                                                        │
│ 오류: (없음)                                                               │
│ 최근 로그 (마지막 40줄) ...                                                  │
│ [결과 파일 열기] [결과 폴더 열기] [전체 로그 열기] [중단 요청: 미지원] [목록에서 숨기기] │
└───────────────────────────────────────────────────────────────────────────┘
```

- 상세 창을 닫으면 숨기기만 합니다. 상단 바와 작업은 그대로입니다.
- 모니터 프로그램을 종료해도 작업 프로세스에는 영향이 없습니다(작업은 별도 프로세스).
- 다시 실행하면 상태 폴더의 기록을 다시 읽어 그대로 표시합니다.

## 3. 상태 표시 규칙

| 상태 | 기호 | 색 |
|---|---|---|
| 대기 | ◌ | 회색 |
| 선행 작업·입력 대기 | ⏸ | 보라 |
| 실행 중 | ▶ | 파랑 |
| 검증 중 | ◎ | 청록 |
| 완료 | ✔ | 초록 |
| 실패 | ✕ | 빨강 |
| 중단 | ■ | 주황 |
| 상태 갱신 없음 / 종료 기록 없음 / 결과 확인 필요 | ⚠ | 노랑 |

색은 보조 수단이고 항상 기호와 상태 이름 글자를 함께 표시합니다.
