# 화면 구성 (시안 B: 다크 캡슐 + 진행 링)

## 1. 캡슐 (항상 떠 있는 작은 막대)

기본 위치는 화면 **위 가운데**입니다. 항상 위에 표시되고, 작업 표시줄·Alt+Tab에는 나타나지 않으며,
클릭해도 다른 창의 포커스를 빼앗지 않습니다. 다른 프로그램이 전체 화면이면 잠시 숨습니다.

```
╭───────────────────────────────────────────────────────────────────────────╮
│ ▦ 앱 6 │ ◔ 3DMaker 54% · sample2 · ≈12:38 │ ⚠ 갱신 없음 측정 │ ✕ 실패 │ ≡ │
╰───────────────────────────────────────────────────────────────────────────╯
```

- `▦ 앱 N`: 바로가기 패널 펼치기/접기 (아래 2).
- 진행 링 칩: 실행·검증 중인 작업. 링 = 진행률(근거가 없으면 빈 링), 이름 · 입력 이름 · `≈예상 완료`.
- 알약(pill): 주의가 필요한 작업 — 노랑 `⚠ 갱신 없음 / 종료 기록 없음 / 확인 필요`, 빨강 `✕ 실패`. 여러 개면 `확인 필요 N`처럼 묶음.
- 칩을 누르면 작업 창에서 그 작업 상세, `≡`는 작업 창.
- 아무 작업도 없으면 `앱` 버튼과 `≡`만 남습니다.
- 우클릭 메뉴: 위치(위·아래 × 왼쪽·가운데·오른쪽), 항상 위, 전체 화면 시 숨기기, 자동 감지, Windows 시작 시 실행, 바로가기 관리, 모니터 종료.
- 빈 곳을 끌어 놓으면 가장 가까운 자리에 붙습니다. 파일·폴더·`.lnk`·주소를 끌어다 놓으면 바로가기로 등록됩니다.

## 2. 바로가기 패널

```
        ╭ 바로가기 · 끌어다 놓아 추가 ─────────── 📌 ╮
        │ ┌───────┐ ┌───────┐ ┌───────┐ │
        │ │  [e]  │ │  [📁] │ │  [📝] │ │
        │ │github │ │Project│ │ 메모장 │ │
        │ └───────┘ └───────┘ └───────┘ │
        │            + 추가              │
        ╰───────────────────────────────╯
```

- 캡슐 바로 아래(캡슐이 아래쪽이면 위)에 펼쳐지는 3열 타일. 아이콘은 원래 프로그램·폴더·바로가기 아이콘.
- 누르면 실행/열기 후 접힘. 📌(작업 창 설정 "패널을 열어 둔 채로")를 켜면 열린 채 유지.
- 타일 우클릭: 열기, 파일 위치 열기, 앞/뒤로, 제거. `+ 추가`: 파일·앱 / 폴더.

## 3. 작업 창

```
┌──┬──────────────────────────┬───────────────────────────────────────────────┐
│≡ │ 작업          확인 1 · 완료 4│ [실행 중] 3DMaker · 입력 sample2                │
│▦ │ ┌──────────────────────┐ │ 3DMaker 영상 생성·측정                          │
│⚙ │ │ ◔54% 3DMaker 영상 생성│ │ 시작 11:20 · 경과 1:11:35 · 마지막 갱신 3초 전    │
│  │ │      실행 중 · sample2│ │ [결과 폴더 열기][결과 파일][전체 로그][작업 폴더]...│
│  │ │      ≈12:38 완료 예상  │ │ ┌단계 예상 완료┐┌처리량────┐┌전체 예상 완료┐  │
│  │ └──────────────────────┘ │ │ ≈14:32      ││462/599 f ││ 정보 부족   │  │
│  │ ┌──────────────────────┐ │ └────────────┘└──────────┘└────────────┘  │
│  │ │ ✕  인코딩 테스트       │ │ 단계  ◔ sample2 생성  실행 중  462/599 77%     │
│  │ │    실패 · 62/200      │ │       ○ sample3 생성  대기                    │
│⏻ │ └──────────────────────┘ │ 결과 · 오류 · 최근 로그                         │
└──┴──────────────────────────┴───────────────────────────────────────────────┘
```

- 사이드바: **작업**(진행 링 카드 목록 + 상세), **바로가기**(등록·이름/인자 수정·순서·제거), **설정**(캡슐 위치·동작·상태 폴더), ⏻ 모니터 종료.
- 창을 닫으면 숨기기만 합니다. 캡슐과 작업은 그대로입니다.
- 모니터 프로그램을 종료해도 작업 프로세스에는 영향이 없습니다(작업은 별도 프로세스).
- 다시 실행하면 상태 폴더의 기록을 다시 읽어 그대로 표시합니다.

## 4. 상태 표시 규칙

| 상태 | 기호 | 색 |
|---|---|---|
| 대기 | ◌ / ⏸ | 회색 |
| 선행 작업·입력 대기 | ⏸ | 보라 |
| 실행 중 | ▶ / 진행 링 | 파랑 |
| 검증 중 | ◎ | 청록 |
| 완료 | ✓ | 초록 |
| 실패 | ✕ | 빨강 |
| 중단 | ■ | 주황 |
| 상태 갱신 없음 / 종료 기록 없음 / 결과 확인 필요 | ⚠ | 노랑 |

색은 보조 수단이고 항상 기호와 상태 이름 글자를 함께 표시합니다. 진행률은 근거(처리량·단계 가중치)가 있을 때만 링에 채워지고,
예상 완료는 항상 `≈`(예상값)로 표시합니다.
